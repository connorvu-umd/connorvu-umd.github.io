ABOUT THE PROJECT

Appointments. Make one or something.

This website is a simple appointment scheduling app concept.

Purpose

The goal was to make booking and managing appointments easier. Visitors can check available dates, select a time, and submit their contact information without needing to call or email.

How it works

Appointment availability is loaded from a JSON data file. When a visitor books or cancels an appointment, the browser saves the updated information locally so it remains available on that device.

This is a front-end class-project prototype. It does not yet have real user accounts, email notifications, or a shared database.
